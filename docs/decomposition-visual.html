01 · Default workflow

Detect broadly. Prove globally.

Event mode detects all eight supported families on the same graph. It delays the final linkage decision until every competing reconstruction has passed—or failed—the same chemical, periodic, topology, and COFid checks.

With linkage="auto", uniqueness is tested across families. A requested family filters only final selection; the diagnostic record still retains every evaluated hypothesis.

02 · Evidence model

Event → site → hypothesis

The refactor separates what was observed locally from what can reconstruct the entire periodic framework. That separation is the core protection against premature linkage assignment.

A site may carry alternatives. A hypothesis chooses one event per site for one family. Only a hypothesis can become complete.

Eight strategies, two shapes

04 · Resolution policy

Local facts first. Global policy last.

The engine resolves only overlaps that chemistry can settle locally. Structural alternatives become branches, while family-wide decisions wait until complete periodic reconstructions can be compared.

Confidence contributes to hypothesis score, but score never chooses between distinct complete family/COFid results. Those remain explicitly ambiguous.

Specific nitrogen context

Context claims endpoints before generic interpretations are emitted.

A
1Pair formal or keto-tautomerized endpoints around N–N as one azine event.
2Recognize carbonyl-bearing partner N as acylhydrazone.
3Then classify remaining C=N/C–N sites as β-ketoenamine or strict imine.
azine / hydrazone > generic overlap

Local overlap only

One event can suppress another only where their claimed chemistry overlaps.

B
1Canonical β-ketoenamine claims its C–N/C=C context.
2A vinylene event cutting an overlapping bond is recorded as locally suppressed.
3Unrelated vinylene and boron events remain eligible; there is no structure-wide veto.
bken > overlapping vinylene only

Global triazine classification

Run only after every family’s hypotheses have completed validation.

C
1Find a complete non-triazine reconstruction.
2Check that every detected C₃N₃ ring stays wholly inside one recovered precursor fragment.
3If so, retain the evidence but remove triazine from complete candidates.

05 · Topology recovery

Fragments become a periodic gain graph

Each hypothesis carries its own cut chemistry into topology validation. Fragments define nodes and incidences; CIF image offsets become integer edge gains whose independent cycle rank supplies the dimensionality constraint.

A supplied topology is validated against the recovered roles and gain graph. Without one, the same graph enters conservative topology auto-detection.

1. Record periodic cuts

Each cut knows both fragment membership and the lattice image connecting its atoms.

(fragmentᵢ, fragmentⱼ, gain)

2. Abstract ring events

Three ring anchors converge on a virtual node. Ditopic precursor fragments collapse into edges; higher-connected fragments remain nodes.

virtual connectivity = 3

3. Match invariantly

Normalize equivalent stacked components, calculate gain-cycle rank, then compare available topology graphs under switching and integer basis changes.

06 · Result contract

Count complete reconstructions

Candidates are deduplicated by (family, COFid). Requested linkage filters apply here; no requested family means all supported families compete.

1

success

2+

Several distinct complete reconstructions survive. All successful hypothesis IDs remain in metadata; none is chosen arbitrarily.

0

FAILED_* / UNSUPPORTED_LINKAGE

No complete result remains. The furthest-progressing failure supplies the reason: topology, chemistry, unexplained framework, endpoint accounting or unsupported chemistry.

graph normalization / detection

Malformed CIF, unsupported non-P1 symmetry, self-image quotient bonding, invalid bond mode, unknown topology, or another structural exception.

i

Diagnostics are first-class output: event_detection stores accepted and locally suppressed events; hypothesis_generation records counts and truncation; hypotheses stores every validation state; event_status states the final classification.

i

Scope boundary: the module targets COFKit’s eight buildable linkage strategies and conservative topology repository. It does not serialize mixed-linkage COFids, expand arbitrary asymmetric units, or infer unrestricted third-party reaction history.
